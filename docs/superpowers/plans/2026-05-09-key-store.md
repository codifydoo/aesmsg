# Slice 2 — Browser key store + wrap/unwrap implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land real `wrapPrivateKey` / `unwrapPrivateKey` in `@aesmsg/crypto` (Argon2id KDF + AES-256-GCM AEAD, versioned JSON envelope), and a new browser-only `@aesmsg/key-store` package that persists wrapped identities in IndexedDB. After this slice, `@aesmsg/crypto` has zero `NotImplementedError` paths and the web app has the storage layer it needs to remember a user's identity across sessions.

**Architecture:** The wrap/unwrap pair stays in `@aesmsg/crypto` (pure crypto, byte-in/byte-out — works in Node + browser). The IndexedDB code lives in a sibling package `@aesmsg/key-store` which the crypto rule "no DOM, no network, no storage" forbids inside `@aesmsg/crypto`. The wrapped envelope is JSON, versioned, and includes the raw public key in plaintext (not secret) so `unwrapPrivateKey` can reconstruct a full `IdentityKeypair` without a separate public-key arg.

**Tech Stack:** `hash-wasm` (Argon2id, ~50–100 KB wasm), Web Crypto for AES-256-GCM, native IndexedDB API (no idb / dexie wrapper — small surface, native is stable). Tests: Vitest (Node + headless Chromium, same setup Slice 1 added). New package follows the same pnpm workspace pattern as the existing three.

**Spec:** [docs/superpowers/specs/2026-05-09-key-store-design.md](../specs/2026-05-09-key-store-design.md)

## Task 5: Implement `wrapPrivateKey` / `unwrapPrivateKey`

The trust-critical pair. Argon2id derives a 32-byte wrap key from the passphrase. AES-256-GCM seals the raw 32 private-key bytes. The raw 32 public-key bytes are stored in the envelope in plaintext (not secret). Errors are differentiated: `BadPassphraseError` for AEAD-open failures (the wrap key didn't match), `DecryptionError` for any other tamper / shape violation, `InvalidFormatError` for envelope parsing.

```ts
import { argon2id } from "hash-wasm";
import { BadPassphraseError, DecryptionError, InvalidFormatError } from "./errors.js";
import { exportRawPrivateKey, importRawPrivateKey, importRawPublicKey } from "./hpke.js";
import { __getIdentityImpl } from "./identity.js";
import type { IdentityKeypair, PublicKeyString, WrappedKey } from "./types.js";
import {
  base64urlDecode,
  base64urlEncode,
  encodePubkey,
  RAW_X25519_PUBKEY_LEN,
} from "./wire.js";

const ENVELOPE_VERSION = 1;
const KDF_ID = "argon2id-aes256gcm";
const KDF_M_KIB = 65536;     // 64 MiB
const KDF_T = 3;
const KDF_P = 1;
const SALT_LEN = 16;
const IV_LEN = 12;
const RAW_X25519_PRIVKEY_LEN = 32;
const AEAD_TAG_LEN = 16;
const CT_LEN = RAW_X25519_PRIVKEY_LEN + AEAD_TAG_LEN;
const WRAP_KEY_LEN = 32;

type Envelope = {
  v: number;
  kdf: string;
  m_kib: number;
  t: number;
  p: number;
  salt: string;
  iv: string;
  ct: string;
  pub: string;
};

async function deriveWrapKey(
  passphrase: string,
  salt: Uint8Array,
  mKib: number,
  t: number,
  p: number,
): Promise<Uint8Array> {
  const raw = await argon2id({
    password: passphrase,
    salt,
    parallelism: p,
    iterations: t,
    memorySize: mKib,
    hashLength: WRAP_KEY_LEN,
    outputType: "binary",
  });
  return raw;
}

async function importWrapKey(raw: Uint8Array): Promise<CryptoKey> {
  const buf = new ArrayBuffer(raw.byteLength);
  new Uint8Array(buf).set(raw);
  return crypto.subtle.importKey("raw", buf, { name: "AES-GCM" }, false, ["encrypt", "decrypt"]);
}

export async function wrapPrivateKey(
  id: IdentityKeypair,
  passphrase: string,
): Promise<WrappedKey> {
  const impl = __getIdentityImpl(id);
  const rawPriv = await exportRawPrivateKey(impl.privateKey);
  const rawPub = impl.publicKeyRaw;

  const salt = new Uint8Array(SALT_LEN);
  crypto.getRandomValues(salt);
  const iv = new Uint8Array(IV_LEN);
  crypto.getRandomValues(iv);

  const wrapKeyRaw = await deriveWrapKey(passphrase, salt, KDF_M_KIB, KDF_T, KDF_P);
  const wrapKey = await importWrapKey(wrapKeyRaw);

  const ivBuf = new ArrayBuffer(iv.byteLength);
  new Uint8Array(ivBuf).set(iv);
  const ptBuf = new ArrayBuffer(rawPriv.byteLength);
  new Uint8Array(ptBuf).set(rawPriv);

  const ctAb = await crypto.subtle.encrypt({ name: "AES-GCM", iv: ivBuf }, wrapKey, ptBuf);
  const ct = new Uint8Array(ctAb);

  const envelope: Envelope = {
    v: ENVELOPE_VERSION,
    kdf: KDF_ID,
    m_kib: KDF_M_KIB,
    t: KDF_T,
    p: KDF_P,
    salt: base64urlEncode(salt),
    iv: base64urlEncode(iv),
    ct: base64urlEncode(ct),
    pub: base64urlEncode(rawPub),
  };
  return JSON.stringify(envelope) as WrappedKey;
}

function parseEnvelope(s: string): {
  salt: Uint8Array;
  iv: Uint8Array;
  ct: Uint8Array;
  pub: Uint8Array;
  m_kib: number;
  t: number;
  p: number;
} {
  let env: unknown;
  try {
    env = JSON.parse(s);
  } catch {
    throw new InvalidFormatError("Wrapped key is not valid JSON");
  }
  if (typeof env !== "object" || env === null) {
    throw new InvalidFormatError("Wrapped key envelope must be an object");
  }
  const e = env as Partial<Envelope>;
  if (e.v !== ENVELOPE_VERSION) {
    throw new InvalidFormatError(`Unknown wrapped key version: ${String(e.v)}`);
  }
  if (e.kdf !== KDF_ID) {
    throw new InvalidFormatError(`Unknown KDF: ${String(e.kdf)}`);
  }
  if (typeof e.m_kib !== "number" || typeof e.t !== "number" || typeof e.p !== "number") {
    throw new InvalidFormatError("KDF parameters missing or wrong type");
  }
  if (typeof e.salt !== "string" || typeof e.iv !== "string" || typeof e.ct !== "string") {
    throw new InvalidFormatError("Required envelope fields (salt, iv, ct) missing or wrong type");
  }
  if (typeof e.pub !== "string") {
    throw new InvalidFormatError("Envelope field 'pub' missing or wrong type");
  }
  let salt: Uint8Array;
  let iv: Uint8Array;
  let ct: Uint8Array;
  let pub: Uint8Array;
  try {
    salt = base64urlDecode(e.salt);
    iv = base64urlDecode(e.iv);
    ct = base64urlDecode(e.ct);
    pub = base64urlDecode(e.pub);
  } catch {
    throw new InvalidFormatError("Envelope field is not valid base64url");
  }
  if (salt.length !== SALT_LEN) {
    throw new InvalidFormatError(`Salt must be ${SALT_LEN} bytes, got ${salt.length}`);
  }
  if (iv.length !== IV_LEN) {
    throw new InvalidFormatError(`IV must be ${IV_LEN} bytes, got ${iv.length}`);
  }
  if (ct.length !== CT_LEN) {
    throw new InvalidFormatError(`Ciphertext must be ${CT_LEN} bytes, got ${ct.length}`);
  }
  if (pub.length !== RAW_X25519_PUBKEY_LEN) {
    throw new InvalidFormatError(`Public key must be ${RAW_X25519_PUBKEY_LEN} bytes, got ${pub.length}`);
  }
  return { salt, iv, ct, pub, m_kib: e.m_kib, t: e.t, p: e.p };
}

export async function unwrapPrivateKey(
  wrapped: WrappedKey,
  passphrase: string,
): Promise<IdentityKeypair> {
  const parsed = parseEnvelope(wrapped as string);
  const wrapKeyRaw = await deriveWrapKey(passphrase, parsed.salt, parsed.m_kib, parsed.t, parsed.p);
  const wrapKey = await importWrapKey(wrapKeyRaw);

  const ivBuf = new ArrayBuffer(parsed.iv.byteLength);
  new Uint8Array(ivBuf).set(parsed.iv);
  const ctBuf = new ArrayBuffer(parsed.ct.byteLength);
  new Uint8Array(ctBuf).set(parsed.ct);

  let rawPriv: Uint8Array;
  try {
    const ab = await crypto.subtle.decrypt({ name: "AES-GCM", iv: ivBuf }, wrapKey, ctBuf);
    rawPriv = new Uint8Array(ab);
  } catch {
    throw new BadPassphraseError();
  }
  if (rawPriv.length !== RAW_X25519_PRIVKEY_LEN) {
    throw new DecryptionError();
  }

  let privateKey: CryptoKey;
  let publicKey: CryptoKey;
  try {
    privateKey = await importRawPrivateKey(rawPriv);
    publicKey = await importRawPublicKey(parsed.pub);
  } catch {
    throw new DecryptionError();
  }

  const publicKeyString = encodePubkey(parsed.pub) as PublicKeyString;
  const impl = {
    publicKey,
    privateKey,
    publicKeyRaw: parsed.pub,
    publicKeyString,
  };
  return impl as unknown as IdentityKeypair;
}
```

```ts
import { IndexedDBUnavailableError } from "./errors.js";
import { DB_NAME, DB_VERSION, STORE_NAME } from "./types.js";

let dbPromise: Promise<IDBDatabase> | null = null;

function openDb(): Promise<IDBDatabase> {
  if (typeof indexedDB === "undefined") {
    return Promise.reject(new IndexedDBUnavailableError());
  }
  return new Promise((resolve, reject) => {
    const req = indexedDB.open(DB_NAME, DB_VERSION);
    req.onupgradeneeded = () => {
      const db = req.result;
      if (!db.objectStoreNames.contains(STORE_NAME)) {
        db.createObjectStore(STORE_NAME, { keyPath: "identityId" });
      }
    };
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error ?? new Error("IndexedDB open failed"));
    req.onblocked = () => reject(new Error("IndexedDB open blocked"));
  });
}

export async function withDB<T>(
  mode: IDBTransactionMode,
  fn: (store: IDBObjectStore) => Promise<T> | T,
): Promise<T> {
  if (!dbPromise) {
    dbPromise = openDb();
  }
  let db: IDBDatabase;
  try {
    db = await dbPromise;
  } catch (err) {
    dbPromise = null;
    throw err;
  }
  return new Promise<T>((resolve, reject) => {
    const tx = db.transaction(STORE_NAME, mode);
    const store = tx.objectStore(STORE_NAME);
    let result: T;
    Promise.resolve(fn(store))
      .then((r) => {
        result = r;
      })
      .catch((err) => reject(err));
    tx.oncomplete = () => resolve(result);
    tx.onerror = () => reject(tx.error ?? new Error("IndexedDB transaction failed"));
    tx.onabort = () => reject(tx.error ?? new Error("IndexedDB transaction aborted"));
  });
}

/**
 * Test helper. Closes the cached DB connection and resets the singleton.
 * Production code should never call this — restart the page instead.
 */
export function __resetDbForTests(): void {
  if (dbPromise) {
    dbPromise
      .then((db) => db.close())
      .catch(() => {
        /* swallow */
      });
    dbPromise = null;
  }
}

/**
 * Test helper. Deletes the entire database. Used by tests' beforeEach.
 */
export async function __deleteDbForTests(): Promise<void> {
  __resetDbForTests();
  if (typeof indexedDB === "undefined") return;
  await new Promise<void>((resolve, reject) => {
    const req = indexedDB.deleteDatabase(DB_NAME);
    req.onsuccess = () => resolve();
    req.onerror = () => reject(req.error ?? new Error("delete failed"));
    req.onblocked = () => resolve();
  });
}
```

```ts
import { withDB } from "./db.js";
import { SchemaVersionMismatchError } from "./errors.js";
import { SCHEMA_VERSION, type StoredIdentity } from "./types.js";

function reqToPromise<T>(req: IDBRequest<T>): Promise<T> {
  return new Promise((resolve, reject) => {
    req.onsuccess = () => resolve(req.result);
    req.onerror = () => reject(req.error ?? new Error("IndexedDB request failed"));
  });
}

function assertSupportedSchemaVersion(record: StoredIdentity): void {
  if (record.schemaVersion !== SCHEMA_VERSION) {
    throw new SchemaVersionMismatchError(record.schemaVersion as unknown as number);
  }
}

export async function saveIdentity(record: StoredIdentity): Promise<void> {
  assertSupportedSchemaVersion(record);
  await withDB("readwrite", (store) => reqToPromise(store.put(record)));
}

export async function loadIdentity(identityId: string): Promise<StoredIdentity | null> {
  const value = await withDB("readonly", (store) =>
    reqToPromise<StoredIdentity | undefined>(store.get(identityId)),
  );
  if (value === undefined) return null;
  assertSupportedSchemaVersion(value);
  return value;
}

export async function hasIdentity(identityId: string): Promise<boolean> {
  const count = await withDB("readonly", (store) =>
    reqToPromise<number>(store.count(identityId)),
  );
  return count > 0;
}

export async function deleteIdentity(identityId: string): Promise<void> {
  await withDB("readwrite", (store) => reqToPromise(store.delete(identityId)));
}

export async function listIdentities(): Promise<StoredIdentity[]> {
  const all = await withDB("readonly", (store) =>
    reqToPromise<StoredIdentity[]>(store.getAll()),
  );
  for (const record of all) assertSupportedSchemaVersion(record);
  return [...all].sort((a, b) => (a.createdAt < b.createdAt ? 1 : a.createdAt > b.createdAt ? -1 : 0));
}
```

```ts
  wrapPrivateKey,

  beforeEach(async () => {
    await __deleteDbForTests();
  });

  it("preserves identity across a save/load/unwrap round-trip and supports message exchange", async () => {
    // 1. Generate a fresh identity in this tab.
    const original = await generateIdentity();
    const originalPk = exportPublicKey(original);

    // 2. Wrap it with a passphrase.
    const wrapped = await wrapPrivateKey(original, "correct horse battery staple");

    const recipient = await importPublicKey(originalPk);

    // 7. Recovered identity decrypts cleanly.
    const out = await open(ct, recovered, aad);
    expect(new TextDecoder().decode(out)).toBe("post-reload hello");
```

## Risks during execution

- **`hash-wasm` API drift.** The Argon2id function name or import shape may have moved. Mitigation: Task 2 Step 2 verifies the import before any code is written; the wrapper in `wrap.ts` is the only file that touches it.
- **Argon2id timing in CI / on slow hardware.** Wrap and unwrap each take 300–800 ms at moderate parameters. Mitigation: per-test timeouts where needed (Task 5 Step 1 already sets 120s on the property test; Task 12 Step 2 documents the 30s fallback).
- **IndexedDB transaction quirks.** Awaiting between two `tx`-bound calls can cause silent abort. Mitigation: every operation goes through `withDB`, which performs exactly one IndexedDB call inside the transaction body — no inter-call awaits.
- **Workspace dep resolution.** `@aesmsg/key-store` declares `@aesmsg/crypto` as `workspace:*`. Mitigation: clean install in Task 13 catches any peer-dep or symlink drift.
- **Coverage gate on `db.ts`.** The `__resetDbForTests` and `__deleteDbForTests` helpers are exercised by every test's `beforeEach`, but the unhappy-path branches (open `onerror`, transaction `onabort`) may be uncovered. Acceptable to drop coverage to 90% if reaching 95% requires contrived tests; tighten the gate when convenient.
